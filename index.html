PREGUNTAS FRECUENTES

Lo importante,
bien claro.

Una base para que el cliente entienda rápido cómo encaja PULSEDESK DIST en su negocio.

¿PULSEDESK DIST sirve solamente para distribuidoras?+

No. Está pensado como una plataforma de gestión para comercios. Se adapta a minimarkets, ferreterías, mayoristas, distribuidoras, kioscos y otros negocios que necesiten ordenar su operación.

¿Puedo usarlo desde más de un dispositivo?+

Sí. La experiencia está preparada para trabajar desde PC, notebook, tablet o celular según el módulo y la necesidad del usuario.

¿Cada usuario puede tener permisos diferentes?+

Sí. La plataforma contempla usuarios, roles y permisos para controlar qué puede ver o hacer cada persona dentro del sistema.

¿Puedo manejar e imprimir listas de precios diferentes?+

Sí. Podés crear listas con descuentos o recargos, asignarlas según cliente o estrategia comercial y generar una versión lista para imprimir.

¿PULSEDESK tiene facturación electrónica?+

Sí. El sistema contempla facturación electrónica conectada con ARCA para emitir comprobantes desde la misma operación.

¿Cómo se calculan las comisiones de vendedores?+

Podés definir una comisión fija por vendedor o configurar porcentajes específicos por categoría o por producto.

¿Qué es SAN?+

SAN es el soporte online integrado a PULSEDESK. Te orienta dentro del sistema y, cuando hace falta, te conecta con Soporte Técnico por WhatsApp.

¿Los datos de cada empresa están separados?+

Sí. La arquitectura del sistema trabaja con aislamiento por empresa para mantener separada la información operativa de cada organización.
